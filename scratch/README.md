# scratch/

> **Reference scripts — not part of the deployable application.**

This directory contains exploratory/learning scripts used during early prototyping.
They are **not** wired into the LexPilot build, test, or deployment pipeline.

## Contents

- **RAG-Langchain-OpenAi/** — A standalone Python RAG prototype using LangChain + OpenAI,
  built as a learning exercise before implementing the production Java/Spring Boot pipeline.

These files are kept in the repo for portfolio context — they demonstrate the learning
path from prototype to production architecture.
